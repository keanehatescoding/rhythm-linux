# Security Policy

## Supported Versions

Only the latest release receives security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub's private vulnerability reporting:

https://github.com/keanehatescoding/rhythm-linux/security/advisories/new

Include what you found, the steps to reproduce it, and the version you tested.

What to expect:

- **Acknowledgement:** within 7 days of your report.
- **Assessment:** we will confirm whether the issue is a vulnerability and tell you the outcome.
- **Fix:** accepted issues are fixed in the latest release, and we will credit you in the advisory unless you ask us not to.
- **Declined reports:** if we decide an issue is not a vulnerability, we will explain why.

We ask that you keep the details private until a fix is released.
